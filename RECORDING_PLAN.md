# Demo video recording plan (the app has no built-in recorder)

ChildShield has simulated videos (captions scanned live) but no video-recording feature, so a complete
demo video must be screen-recorded. Windows: Win+G (Xbox Game Bar) or OBS Studio. Mac: Shift+Cmd+5.
Open http://localhost:5173 in Chrome, 1920x1080, zoom 100%, record 5-6 minutes.

| # | Time | Do this | Say / show |
|---|------|---------|------------|
| 1 | 0:00 | Register (or dev demo account), SAVE the recovery code | Login, recovery code, MetaMask approval toggle |
| 2 | 0:40 | Child Profile: name, age 10, Save | Age groups, thresholds |
| 3 | 1:10 | Content Check: SAFE, WARNING, BLOCKED samples | Blocked screen + parent alert |
| 4 | 2:00 | Child Overlay Demo > YouTube > tap a 13+ video | Age popup auto-appears; Use camera > Scan face; show estimate range, confidence, "Uncertain" case (cover the camera / dim light) and the disclaimer |
| 5 | 3:00 | Type "i feel so alone and hopeless" in the phone keyboard | Helpline popup + parent toast |
| 6 | 3:40 | Open Puzzle Pop, wait ~7 s | Ad blurred + alert |
| 7 | 4:20 | Blockchain tab: Connect wallet, Anchor on Sepolia, Simulate tampering | Hash chain break |
| 8 | 5:00 | Alerts, Activity, Dashboard, Privacy (delete data) | Live updates, zero content storage |
